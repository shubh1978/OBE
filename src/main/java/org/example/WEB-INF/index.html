Step 0 — Assign Student Specializations (Run Once)

REQUIRED

Upload the enrolment Excel file (e.g. 2023 24.xlsx) — the file with columns: SR NO, Roll No, Student Name, Programme Name. This API reads each student's full programme name, matches it to a specialization in the database, and stamps specialization_id on every student record. Without this step, the specialization filter will always show all students.

📝 Upload Single Mark Sheet (Question-Wise Report)

Upload a single question-wise marks entry report Excel (.xlsx) file directly — no ZIP needed.
Same format as the SOET mark sheets (e.g. ETCS206A COMPUTER GRAPHICS (mid term).xlsx).

e.g. "COURSECODE NAME (mid term).xlsx"

📊 Upload Question-Wise Marks Report

Upload the university Question wise marks entry report Excel (e.g. Question wise marks entry report Odd sem.xlsx).
Format: Sheet2 with Roll no, Course Code, Class Name, Component Name, Q1…Q24.
Component → exam type: Class Test (Freq 1) → mid_term (max 20)  |  End Term Examination → end_term (max 50)
Practical Internal / External and Class Test Frequency 2 are automatically skipped. Safe to re-upload — duplicates are never created.

Click or drag Question-Wise Report .xlsx here

e.g. "Question wise marks entry report Odd sem.xlsx"

📋 Upload University Result Excel (Mid + End Term Marks)

⚠️ This card is ONLY for the university result file (e.g. Result Odd Sem 2025-26.xlsx) that has a Sheet2 with student marks.
To upload a CO-PO mapping structure file, scroll down to the 📊 Upload CO-PO Mapping Sheet card instead.

Reads Sheet2 — one row per student-course.
Internal Marks → mid_term (max 20)  |  External Marks → end_term (max 50)
Absent (Grade=AB) rows are skipped. Re-uploading is safe — duplicates are never created.
